# Halaqoh Tahfidz — Final

## Fitur
- Santri awal kosong.
- Admin satu-satunya yang menambah/menghapus santri.
- Admin membuat akun ustadz.
- Admin membuat kelompok dan menentukan ustadz.
- Ustadz hanya melihat santri binaannya.
- Pencatatan setoran hafalan.
- Rekap pekanan, bulanan, semester.
- Admin DAN Ustadz dapat mengunduh PDF.
- PDF berisi nama halaqoh, ustadz, periode, jumlah santri, total setoran, rata-rata nilai, rincian santri, hafalan terakhir, catatan, dan tanda tangan.
- PDF Ustadz otomatis hanya memuat santri/halaqoh binaannya.
- UI responsif dan modern.

## Demo
Admin: `admin` / `admin123`
Ustadz: `ustadz` / `ustadz123`

## Upload
Upload `index.html`, folder `assets`, dan `README.md` ke root repository. Untuk GitHub Pages, pilih branch `main` dan folder `/ (root)`.

## Catatan keamanan
Ini versi static frontend untuk GitHub Pages. Data disimpan di browser (localStorage), sehingga bukan sistem produksi multi-perangkat. Untuk penggunaan nyata dengan data sensitif, gunakan backend/database dan autentikasi server.
